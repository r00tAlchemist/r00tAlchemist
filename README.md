## 🛡️ Обо мне

Специалист по информационной безопасности на стыке Blue и Red Team. Я смотрю на инфраструктуру глазами атакующего, чтобы лучше её защищать: воспроизвожу технику сам, разбираю, какой след она оставляет в логах, и пишу правило, которое её ловит.

В коммерческом пентесте я прошёл путь от веб-приложения до удалённого выполнения кода на сервере 1С — а затем написал открытый набор детектов, который обнаруживает такие атаки. Так же работаю в своей лаборатории: отрабатываю атаки на Active Directory и запускаю ВПО, а потом проверяю, что из этого увидели SIEM, IDS и EDR.

В свободное время развиваю open-source инструменты для SOC: детекты для 1С на Sigma и Wazuh, тренажёр триажа на 28 сценариев и аудит средств мониторинга на хосте.
